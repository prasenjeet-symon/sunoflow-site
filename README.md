# SunoFlow — landing page

The marketing site for **SunoFlow**, published with GitHub Pages at
<https://prasenjeet-symon.github.io/sunoflow-site/>.

A static page with no build step and no third-party dependencies: one HTML
file, one stylesheet, one small script.

```
index.html        the page
assets/styles.css
assets/app.js
assets/favicon.svg
.nojekyll         serve the files as-is, no Jekyll processing
```

To work on it locally, serve the folder over HTTP and open it in a browser.

> This repository contains the website only. The SunoFlow application itself
> lives in a separate, private repository.
